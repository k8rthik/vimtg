# README demo inputs

These files drive the recording in [`../demo.gif`](../demo.gif), generated by
[`../demo.tape`](../demo.tape) with [vhs](https://github.com/charmbracelet/vhs).

| File | Purpose |
|------|---------|
| `krenko.deck` | The sample 100-card Commander deck shown in the demo |
| `cards.json` | A small Scryfall-format card list: just the cards in `krenko.deck`, with their oracle text. Prices are left empty |
| `setup.sh` | Sourced off camera by the tape. Builds a temporary sandbox (`XDG_*` dirs) and loads `cards.json` with `vimtg sync`, without network access |

To regenerate, run this from the repository root:

```bash
uv sync
uv run vhs docs/demo.tape
```

vhs needs `ttyd`, `ffmpeg` and a Chromium it can find on `PATH`. When you
run it as root (in a container, for example), set `VHS_NO_SANDBOX=true`.
The sample hand uses a fixed seed (`:hand 10`), so every run records the
same session.
